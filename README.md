# Azariel Senior Secondary School Website

## 🌟 Overview
This is the official website for Azariel Senior Secondary School, a no-fee public school located in Matatiele, Eastern Cape, South Africa. We offer quality education for learners in Grades 8-12. Our motto is "Soar Like an Eagle."

## 📊 Key Facts
- **Location:** Matatiele, Eastern Cape, 4730
- **Education District:** Alfred Nzo West Education District
- **Grades:** 8-12
- **Fee Status:** No-Fee Public School
- **2024 Matric Pass Rate:** 87.1%
- **Motto:** Soar Like an Eagle

## 🛠️ Tech Stack
- React 19 with TypeScript
- Vite for fast development and builds
- Tailwind CSS v4 for styling
- Framer Motion for animations
- React Router v7 for navigation

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

## 📁 Project Structure
```
src/

├── pages/         # Page components
├── admin/         # Admin panel components
├── services/      # API and business logic
├── lib/           # Utility functions
└── main.tsx       # Entry point
```
